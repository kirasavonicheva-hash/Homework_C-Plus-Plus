Задание.6
Разница в типе результата. Выражение 7 / 2 вернет целое число 3, а 7.0 / 2 вернет дробное число 3.5.
Причина в типах данных. В первом случае оба числа целые,
поэтому выполняется целочисленное деление с отбрасыванием остатка.
Во втором случае число 7.0 является числом с плавающей точкой,
поэтому второе число автоматически преобразуется в дробное и выполняется обычное математическое деление.
