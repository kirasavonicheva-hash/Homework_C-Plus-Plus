## Задание.1

До компиляции и запуска оператор `static_cast<int>` просто отбросит дробную часть у всех чисел:
* `7.9 -> 7`
* `7.3 -> 7`
* `-7.9 -> -7`
* `-7.3 -> -7`

Вывод программы:

```text
7.9 -> 7
7.3 -> 7
-7.9 -> -7
-7.3 -> -7
```

## Задание.3 

Вывод программы:

```text
Часы: 8.35, ставка: 250
Время: 8 ч 21 мин
Заработок: 2087 руб 50 коп
```

Если удалить `+ 0.5` из расчёта минут программа выводит `20 мин`, а не `21 мин`. 

Хвост double ломает:
1. Потеря точности при вычислениях.
2. Переполнение, если результат превышен нормы то хвост сломается.
3. Прямое сравнение на равенство без учета погрешности.
